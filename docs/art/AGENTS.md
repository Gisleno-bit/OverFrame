# Game art coordination

This directory belongs to the Rust fighting game in `Gisleno-bit/OverFrame`. Read [REPOSITORY_MAP.md](REPOSITORY_MAP.md), [WORKFLOW.md](WORKFLOW.md), [ROLES.md](ROLES.md) and the current dated review before changing its specs or evidence.

Explicit current user instructions take precedence. Preserve the agreed ownership: ChatGPT authors visual specifications/reviews; Claude authors game implementation, tests, capture/export tooling and CI. Preserve existing work and inspect Git identity/status before edits. The nested `Overframe/` checkout is an independent Electron browser-overlay repository and is not part of the game.

Keep source and evidence SHAs explicit. Preserve history and report current verification honestly. No simulation, hitbox, capsule, scale or bone-length changes are authorized merely to make art fit. Do not approve art without actual matching `game3d` images, or treat `not_run` as pass.

Follow the concrete handoff and verification steps in WORKFLOW.md. These instructions are scoped to game art coordination; they do not install hooks, change code ownership or import the overlay's development rules.
